# 公司办公场景 3D — 快速上手（v02 · 30 工位小公司）

一个「像真公司」的总部办公层：13 个独立房间、30 个工位、235 件真家具、
**26 人坐着办公 + 8 人在走廊走动**（带骨骼与走路动画）。

---

## 一条命令

```bash
cd company_3d && ./build_scene.sh          # 默认 8 个巡游人物
```

它依次完成：生成平面布局 → Blender 建场景 → 渲染 6 张预览。
产物：

| 文件 | 内容 |
|---|---|
| `02_scenes/wip/scn_company-hq_v02.00_wip.blend` | 场景工程（427 对象 / 43 材质） |
| `02_scenes/wip/scn_company-hq_v02.00_wip.glb` | 导出模型（**含走路动画**） |
| `05_renders/preview/rnd_company-hq_*_v02.00.png` | 6 张预览：总览 / 俯瞰 / 开放办公区 / 董事长室 / 走廊 / 前台 |

```bash
./build_scene.sh 12        # 12 个巡游人物
./build_scene.sh 0         # 无人走动，全部坐在工位
```

## 场景规格

| 项 | 值 |
|---|---|
| 楼层 | **34 × 24 m = 816 m²**，层高 3.2 m |
| 人均面积 | 27.2 m²/人（含会议室等公共面积） |
| 员工 | **30 人**：研发部 12 / 市场部 8 / 运营部 6 / 财务部 4 |
| 房间 | **13 间** |
| 工位 | 30 个（桌面 1.5×0.75 m，间距 1.7×1.9 m） |
| 家具 | **235 件**（真家具：多部件建模，非方块） |
| 人物 | 26 个就座 + 8 个巡游（可调） |

### 13 个房间

```
北排  董事长办公室 │ 总经理办公室 │ 大会议室 │ 茶水间
      ─────────────── 走廊 ───────────────
中排  研发部办公室 │ 市场部办公室 │ 运营部办公室
      ─────────────── 走廊 ───────────────
南排  财务部办公室 │ 小会议室 │ 前台接待 │ 休息区 │ 卫生间 │ 储物打印
```

每个房间都有独立隔墙 + 门洞（门开向走廊）。地板按用途分材质：
高管室/会议室用木地板，办公区用地毯，茶水间/卫生间用瓷砖。

### 家具类型（共 38 种）

工位类：工位桌（桌面+侧板+挡板+抽屉）、五爪办公椅（座面+靠背+扶手+气压杆+5 爪+滚轮）、
显示器、键盘、活动柜；老板台、行政椅、会客椅；

会议类：长会议桌、圆桌、会议椅、显示屏、白板；

接待/休闲类：前台接待台、沙发、单人沙发、茶几、地毯、电视；

茶水/卫生类：操作台（带吊柜）、水槽、咖啡机、饮水机、冰箱、吧台椅；

其它：书柜（含书）、储物架、文件柜、打印机、碎纸机、绿植（大/小）、
垃圾桶、落地灯、logo 墙、卫生间隔间、洗手台。

> **性能**：所有家具用「原型网格 + 实例化」共享几何。
> 427 个对象只对应约 40 份网格数据，构建约 4–6 秒。

## 人物与动画

### 角色构成
低多边形人形，单一网格 + 顶点组蒙皮，材质分区明确：
皮肤 / 上衣（**部门配色**）/ 裤子 / 头发 / 鞋。

- 研发部 `#4C7DFF`（蓝）　市场部 `#FF6B35`（橙）
- 运营部 `#28C76F`（绿）　财务部 `#FFB020`（黄）

另外单独放置：董事长、总经理、前台、门口访客（否则这些房间是空的）。

### 骨骼
`root → hips → spine → neck → head`，四肢各 3 节：
`upperarm/forearm/hand` 与 `thigh/shin/foot`（分 L/R）。

### 动画
- **走路循环**：24 帧（1 秒 @24fps），关键姿势在 0/6/12/18/24 帧，
  大腿前后摆 ±34°、小腿屈伸、手臂反相摆动、躯干轻微起伏。
- **巡游**：从走廊节点图随机游走 3–6 跳，位置与朝向按路径插值
  （LINEAR），速度 1.0–1.6 m/s 随机。
- **坐姿**：大腿前抬 78°、小腿下垂 74°、上臂前伸 56°，髋部下沉 0.40 m 到座面高度。

> 在 Blender 里打开 `.blend`，**按空格播放**即可看到人物沿走廊走动。

### 行走路径
路径是走廊节点网络，**已验证 0 条斜线、0 条穿墙**：
两条横向走廊骨架（Y=16 / Y=7）+ 一条纵向连接（X=17.2），
每个房间的门节点垂直接到最近的走廊骨架上。

## 坐标系

Z 轴向上，原点在楼层西南角，单位米 —— 与 Blender 完全一致。
导出 `.glb` 时保持一致，可直接进引擎。

## 数据绑定

场景中的每个人都对应 `data/company_desks.csv` 的一行：

```
employee_id → 部门 → 工位 desk_id → 坐标 (desk_x, desk_y, desk_rot) → 离职风险
```

| 数据 | 文件 | 可用于驱动 |
|---|---|---|
| 离职风险 | `data/link_employee_risk.csv` | 人物/工位高亮色 |
| 日常行为 | `data/link_daily_behavior.csv` | 在座 / 离座 / 加班动画 |
| 工作质量 | `data/link_work_quality.csv` | 工位状态显示 |
| 谈话报告 | `data/link_talk_reports.csv` | 人物气泡 / 标签 |
| 测评报告 | `data/link_survey_reports.csv` | 人物状态 |
