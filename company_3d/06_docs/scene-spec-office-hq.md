# 场景规格书 — 办公楼总部室内场景 (office-hq)

> 场景代号 `office-hq`　版本 v01.00　状态 `_wip`
> 本文档是**建模执行的唯一依据**：尺寸、分区、坐标、资产清单、命名全部以此为准。

## 1. 场景概述

| 项 | 值 |
|---|---|
| 类型 | 办公楼内景 · 开放办公区 |
| 楼栋 | A 栋 3F/4F/5F、B 栋 2F，共 **4 层** |
| 单层尺寸 | **64 m (X) × 44 m (Y)** = 2816 m² |
| 层高 | **3.2 m**（吊顶下净高 2.9 m） |
| 总建筑面积 | 11264 m² |
| 工位总数 | 1404 个（实际投用 1164 人） |
| 人均面积 | 9.7 m²/人（含会议室等公共面积） |
| 部门 | 市场部 / 研发部 / 财务部 / 运营部 |
| 主要用途 | 数字孪生：把员工行为与状态数据绑定到场景人物 |

**主展示层**：`A栋-3F`（本文档所有图纸与坐标均以此层为准；其余三层结构相同）。

## 2. 坐标系与单位（必须严格遵守）

| 项 | 约定 |
|---|---|
| 单位 | 米 (meter) |
| 向上轴 | **Z**（Blender 默认，无需转换） |
| 原点 | 楼层**西南角**（左下角），位于楼板顶面 |
| X 方向 | 楼层宽度方向，向右为正，范围 0 → 64 |
| Y 方向 | 楼层进深方向，向上为正，范围 0 → 44 |
| Z 方向 | 高度，楼板顶面为 0，吊顶 3.2 |

导出格式：`.blend`（工作）→ `.glb`（引擎）→ `.fbx`（备选）。
导出时**应用全部变换**（Apply Transform），保持 1 单位 = 1 米。

- **柱网**：8 m × 8 m，柱截面 0.6 × 0.6 m，共 40 根/层

## 5. 数据绑定（数字孪生的关键）

场景不是静态模型，需要把员工数据绑到每个工位上：

| 绑定项 | 数据来源 | 用途 |
|---|---|---|
| 员工 ↔ 工位 | `data/office_desks.csv` | 每人固定座位，与部门分区一致（一致率 100%） |
| 部门 ↔ 分区 | 上表 `z_*` | 决定工位所在区块与配色 |
| 风险评分 | `output/employee_risk_scores.csv` | 驱动人物/工位高亮色 |
| 行为指标 | `data/link_daily_behavior.csv` | 驱动人物动画（在座/离座/加班） |
| 工作质量 | `data/link_work_quality.csv` | 驱动工位状态显示 |
| 谈话/测评 | `data/link_talk_reports.csv`、`link_survey_reports.csv` | 驱动人物表情/气泡标签 |

**人物占位体 → 真实角色替换位**：Blender 脚本可先用
`--people 1` 生成半透明占位体确认布局，后续用绑定角色按 `employee_id` 替换。
